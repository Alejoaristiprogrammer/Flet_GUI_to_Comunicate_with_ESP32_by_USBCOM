# Flet_GUI_to_Comunicate_with_ESP32_by_USBCOM
This is a Flet GUI to read an image, resize to a desired image and send it to the ESP32 by USB Serial communication. The GUI also have a "console" window to check messages sent from the ESP32 to the interface. 
Terminal command to install required libraries:
pip install flet opencv-python matplotlib pyserial numpy
